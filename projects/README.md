# Portfolio project folders

Create one lowercase, hyphenated folder per project:

```text
projects/project-name/
├── case-study/   Primary downloadable case study
├── creatives/
│   ├── square/   1:1 carousel assets
│   ├── portrait/ Portrait social assets
│   ├── landscape/
│   └── video/
├── documents/    Supporting plans, kits and reports
└── data/         Trackers, spreadsheets and structured notes
```

Use descriptive, lowercase filenames. Keep carousel images at the same dimensions inside each carousel. After adding a project, duplicate a `.project-card` block in `index.html` and update its file paths and copy.
